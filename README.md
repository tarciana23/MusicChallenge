# 🎧 Music Challenge

Projeto desenvolvido com **Vite Vanilla** que interage com a **API do Spotify** para coletar informações sobre artistas e gêneros musicais.

---

## ✅ Requisitos

📌 Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.
🔄 Recomenda-se usar a versão mais recente do Node.js.

---

## 📦 Instalação

1. 🔁 Clone este repositório:

   ```bash
   git clone https://github.com/tarciana23/MusicChallenge
   ```

2. 📂 Acesse o diretório do projeto:

   ```bash
   cd MusicChallenge
   ```

3. 📥 Instale as dependências:

   ```bash
   npm install
   ```

---

## 🚀 Executando o Projeto

Após instalar as dependências, inicie o servidor de desenvolvimento com o comando:

```bash
npm run dev
```

Isso iniciará o **Vite** e abrirá a aplicação no navegador. A interface estará disponível para interação.

---

## 🗂️ Estrutura do Projeto

```
📁 public/           → Arquivos estáticos (imagens, ícones, etc.)
📁 src/              → Código-fonte da aplicação
📄 index.html        → Arquivo HTML principal
🛠 vite.config.js    → Configuração do Vite
```

---

## ⚙️ Configuração de Ambiente

Se precisar configurar variáveis de ambiente, crie um arquivo `.env` na raiz do projeto e adicione as chaves necessárias:

```env
VITE_MY_CLIENT_ID=seu_client_id_aqui
VITE_MY_CLIENT_SECRET=seu_client_secret_aqui
```
